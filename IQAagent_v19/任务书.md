# 基于开源多模态大模型的图像质量评估 Agent 框架任务书

## 1. 任务目标

构建一套图像质量评估 Agent 框架。在不使用目标评测数据进行模型训练或微调的前提下，通过 Skill（Prompt）充分挖掘开源多模态大模型自身的图像质量感知与评分能力。

## 2. 基础模型

选用 Qwen2.5-VL、Qwen3-VL 等参数规模为 7B 或以上的开源多模态大模型作为 Backbone。

## 3. 评测数据集

使用以下两个图像质量评估数据集：

- **KonIQ-10k 验证集（Val Set）**  
  下载链接：[https://pan.baidu.com/s/1RQ_13w-LcmllA6MOapSI_w?pwd=m164](https://pan.baidu.com/s/1RQ_13w-LcmllA6MOapSI_w?pwd=m164)

- **SPAQ 测试集（Test Set）**  
  数据集图片可从公开网络资源获取；标签下载链接：  
  [https://pan.baidu.com/s/1sHo5DoxnBB4_kPZdD_6a8Q?pwd=1ctu](https://pan.baidu.com/s/1sHo5DoxnBB4_kPZdD_6a8Q?pwd=1ctu)

## 4. 核心要求

### 4.1 禁止基于评测数据训练

- 不得使用上述评测数据集对 Backbone 大模型进行训练或微调。
- 大模型调用的任何 Tool、辅助模型或外部模块，均不得使用上述评测数据集进行训练或参数优化。

### 4.2 基于 Skill 完成质量评估

- 仅允许通过 Skill（Prompt）向大模型注入图像质量评估规则、分析流程和评分标准。
- 系统需要在 KonIQ-10k 验证集和 SPAQ 测试集上直接输出图像质量评分。
- 评测目标是在两个数据集上取得尽可能高的 **SRCC** 和尽可能低的 **MAE**。

### 4.3 Router/Decision 层的可优化范围

仅允许对 Router/Decision 层进行训练或提示优化，且优化内容仅限于：

- 评估规则的选择；
- 多条规则之间的冲突裁决；
- 评估结果的解释生成。

### 4.4 禁止使用数据集捷径

以下信息不得作为 Router、LLM 或 Skill 的线上输入：

- 数据集名称；
- Image ID；
- 文件名；
- MOS；
- Source Score 或其他来源评分；
- 失真类型；
- 失真等级；
- Train/Test Split 信息；
- 其他能够直接或间接泄露数据集标签、划分或样本身份的信息。

### 4.5 MOS 的使用边界

MOS 仅允许用于：

- 离线 Oracle 标签构造；
- 离线性能评测；
- 离线误差分析。

MOS 及其任何直接或间接衍生信息均不得进入线上推理阶段，也不得作为 Skill、Router 或 LLM 的输入。

## 5. 一句话总结

> 在不使用目标评测数据集训练或微调模型的前提下，通过 Skill 与受限的 Router/Decision 机制，充分挖掘开源多模态大模型自身的图像质量评估能力。
